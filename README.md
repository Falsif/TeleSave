# TeleSave — личный архив переписок Telegram

TeleSave подключается к **вашему** аккаунту Telegram через официальный API (Telethon) и сохраняет
копии сообщений из выбранных чатов на ваш компьютер. Если собеседник потом удалит сообщение,
копия останется в архиве с отметкой **«Удалено в Telegram»**.

> TeleSave не восстанавливает сообщения, удалённые **до** того, как программа их сохранила.
> Секретные чаты и самоуничтожающиеся сообщения через API недоступны и не сохраняются.

---

## Возможности

- Вход по номеру телефона, коду из Telegram и облачному паролю (2FA). Без ботов.
- Список всех переписок (личные, группы, каналы) с переключателем «Сохранять».
- Автосохранение входящих и исходящих сообщений: дата и время, имя отправителя, текст, эмодзи, ссылки
  (в том числе скрытые за текстом), пересылки.
- Фото, видео, голосовые и документы — по желанию (переключатели и лимит размера в настройках).
- Правки: отметка «изменено» и история предыдущих версий.
- Удаления: отметка «Удалено в Telegram», сообщение остаётся в архиве.
- Работа в системном трее, запуск вместе с Windows (стартует свёрнутым).
- Загрузка всей доступной истории чата или только за период.
- Избранное, медиатека, поиск по словам и датам, фильтр «только удалённые».
- Экспорт в HTML / TXT / JSON (с вложениями или без).
- Резервные копии и восстановление (в том числе на другом компьютере).
- Чтение архива без интернета, время последней синхронизации.
- Тёмная и светлая темы, плавные анимации.
- Автоматическое переподключение после потери интернета и досинхронизация пропущенного.

## Безопасность

- Всё хранится только локально, в выбранной вами папке. Программа обращается только к серверам Telegram.
- Архив зашифрован AES-256-GCM: тексты, имена, аватары, сессия Telegram, API-ключи и все вложения.
- Ключ шифрования хранится в `keystore.json` в зашифрованном виде:
  - без пароля — через Windows DPAPI (открыть архив может только ваша учётная запись Windows);
  - с паролем — через scrypt; без пароля архив не открыть (забытый пароль восстановить нельзя).
- Пароли нигде не хранятся в открытом виде. В логах нет содержимого сообщений.
- Не зашифрованы только служебные данные: даты сообщений и числовые id (нужны для поиска по датам).
- При открытии вложения его копия временно расшифровывается в `%TEMP%\TeleSave_view` и удаляется при выходе.
- Экспорт (HTML/TXT/JSON) создаётся **без шифрования** — храните его бережно.

## 1. Получение API ID и API Hash (один раз)

1. Откройте <https://my.telegram.org> и войдите по номеру телефона (код придёт в Telegram).
2. Нажмите **API development tools**.
3. Заполните форму: App title — `TeleSave`, Short name — например `telesave123`, Platform — **Desktop**.
4. Скопируйте **App api_id** (число) и **App api_hash** (32 символа).
5. При первом входе TeleSave попросит ввести их. Никому не передавайте эти ключи.

## 2. Запуск из исходников

Нужен **Python 3.11 или 3.12** (python.org, при установке отметьте «Add python.exe to PATH»).

```bat
cd TeleSave
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Или просто дважды щёлкните `run.bat`.

## 3. Установщик — как у обычных программ

Результат — файл **`TeleSave-Setup-1.0.0.exe`**: мастер установки на русском, ярлык в «Пуске»
и (по желанию) на рабочем столе, удаление через «Параметры → Приложения». Права администратора не нужны,
Python на компьютере для работы программы не нужен. При удалении программы архив переписок **не** удаляется.

### Вариант А — собрать у себя (один раз)
1. Установите Python 3.12 (python.org, галочка «Add python.exe to PATH»).
2. Установите Inno Setup: в командной строке `winget install JRSoftware.InnoSetup`
   (или скачайте с jrsoftware.org).
3. Дважды щёлкните **`build.bat`**. Через несколько минут откроется папка `output`
   с готовым `TeleSave-Setup-1.0.0.exe`.

### Вариант Б — без установки чего-либо (GitHub собирает сам)
1. Загрузите папку проекта в новый репозиторий на GitHub.
2. Вкладка **Actions** → «Сборка TeleSave» → **Run workflow**.
3. Через ~5 минут откройте завершённый запуск и скачайте артефакт **TeleSave-Setup** (zip с установщиком).
   Если создать тег `v1.0.0`, установщик появится ещё и во вкладке **Releases**.

> Windows SmartScreen может предупредить «Неизвестный издатель» — у программы нет платной цифровой
> подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

## 4. Первый запуск

1. Выберите папку для архива (по умолчанию `Документы\TeleSave`) и, по желанию, пароль.
2. Введите API ID / API Hash, номер телефона, код из Telegram и, если включён, облачный пароль.
3. Откройте **«Все переписки»** и включите **«Сохранять»** у нужных чатов.
   При включении сразу сохраняются последние 100 сообщений, дальше — всё новое.
4. Для старых сообщений: меню `⋯` у чата → «Сохранить всю доступную историю» или «за период».

## Как работает сохранение

- Пока программа запущена (окно или трей), новые сообщения, правки и удаления приходят мгновенно.
- Каждые N минут (настройка) и после восстановления интернета программа догружает всё,
  что пришло за время простоя, и сверяет последние 50 сообщений каждого чата (правки и удаления).
- Если программа была выключена, при следующем запуске новые сообщения догрузятся.
  Удаления и правки за время простоя распознаются только среди последних 50 сообщений чата.
- Вложения скачиваются в фоне. Если сообщение удалили раньше, чем вложение успело скачаться,
  оно будет помечено как недоступное.
- Повторное сохранение одного и того же сообщения невозможно (ключ «чат + id сообщения»).

## Структура папки архива

```
TeleSave\
  keystore.json     зашифрованный ключ архива
  archive.db        база SQLite (содержимое зашифровано)
  settings.json     настройки (без секретов)
  media\<чат>\*.tsf зашифрованные вложения
  logs\             журнал работы (без текста сообщений)
```

## Частые вопросы

**Telegram пишет «подождите N секунд».** Это защита от частых запросов (FloodWait). TeleSave ждёт сам;
при загрузке большой истории это нормально.

**Перенёс папку архива на другой компьютер — не открывается.** Без пароля ключ привязан к учётной
записи Windows. Используйте «Настройки → Резервные копии»: копия восстанавливается где угодно по её паролю.

**Как выйти из программы полностью?** Правый клик по значку в трее → «Выход».

**Можно ли пользоваться Telegram одновременно?** Да. TeleSave — отдельный сеанс вашего аккаунта
(виден в Telegram → Настройки → Устройства как «TeleSave (Windows)»).
